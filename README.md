# La Grieta

Veinte videos de cinco minutos para YouTube. Cada episodio es una animación 3D documental: una escena renderizada, cámara en movimiento y narración en español. La teoría se cuenta como teoría. Al lado va lo que sí está documentado.

Cada carpeta en `episodios/` trae:

- `video.mp4` — 1280×720, 5:00 exactos, con audio
- `audio.mp3` — narración sola
- `titulo.txt` — título para YouTube
- `descripcion.txt` — descripción y hashtags, listos para pegar
- `miniatura.jpg` — imagen del episodio
- `guion.txt` — texto narrado
